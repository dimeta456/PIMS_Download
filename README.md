# PIMS 后台下载

按 **App 版本号** 下载对应后台。版本号必须一致，例如 App 2.9.21 使用 Release `2.9.21`。

打开 [Releases](https://github.com/dimeta456/PIMS_Download/releases)，选择和自己 App 相同的版本，下载 `public_Manage_*.zip`。

版本对照也写在 [`versions.json`](versions.json)。以后每发一个后台，就新增一个同名 Release，并在这个文件里加一行。

| App 版本 | 后台包 | 下载 |
|---|---|---|
| 2.9.21 | public_Manage_1106 | [public_Manage_1106.zip](https://github.com/dimeta456/PIMS_Download/releases/download/2.9.21/public_Manage_1106.zip) |

压缩包里有 SQL Server 版和 SQLite 版。用哪种数据库，就进哪个目录。
